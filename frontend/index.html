02 — AI Systems

Production Agents Over Enterprise Data

People make real decisions on what an agent outputs. This is the pipeline I build so those decisions are safe — the validation layer carries more weight than the model.

01

Ingest & Contract

SAP extracts, HR exports and finance spreadsheets pulled with pandas / openpyxl, then forced through an explicit Pydantic schema contract — types, ranges, nullability, referential keys, date and currency normalisation. Rows that fail are quarantined with a reason code, never silently coerced.

pandasopenpyxlPydanticSAP extracts
02

Reconcile & Profile

Row counts and control totals reconciled against the source system before anything is queryable. Period-over-period deltas, outlier detection (IQR / z-score / rule thresholds), duplicate and orphan checks, and freshness/completeness scoring per feed. A failed reconciliation blocks the load and raises an alert.

Control totalsOutlier detectionDrift checksData SLAs
03

Store & Retrieve

PostgreSQL as the system of record, pgvector for embeddings in the same database — so semantic search and relational filters run in one transaction. Hybrid retrieval (SQL predicates + vector similarity), row-level security by entity and cost centre, and every chunk carrying lineage back to its source row.

PostgreSQLpgvectorHybrid searchRow-level access
04

Plan & Reason

An explicit agent graph (LangGraph / Semantic Kernel / custom state machine): plan → select tool → act → critique → answer, with bounded steps and no infinite loops. Numbers come from deterministic SQL and Python tools, never from the model's arithmetic. Responses are JSON-schema-constrained structured output, validated before they leave the service.

LangGraphSemantic KernelTool callingStructured output
05

Guard & Escalate

No answer ships without a citation to the underlying row. Confidence thresholds, disagreement between tool result and narrative, or data older than its SLA all trigger an escalation to a human rather than a guess. Write actions sit behind human-in-the-loop approval; PII is masked before it ever reaches a prompt.

Escalation pathsHuman-in-the-loopCitationsPII masking
06

Version & Evaluate

Prompts are versioned artefacts in Git, not strings in code — each with an ID, changelog, and pinned model version. A golden-set evaluation harness runs in CI on every prompt or model change, gating regressions on accuracy, schema validity, refusal rate and cost. Rollback is a redeploy of the previous prompt version.

Prompt versioningGolden setsRegression gatesCI/CD
07

Observe & Audit

Every run emits a full trace — prompt version, retrieved context, each tool call and its arguments, token spend, latency, and the final structured payload. Dashboards on quality and cost per workflow; an auditor can reconstruct exactly why the system said what it said, months later.

Trace loggingCost telemetryGrafanaAudit trail
